Android page: Settings > App specific settings

One app, one override

Select an installed app to create a profile for it. An app profile contains the same Touchpad, Cursor, Swipe, Actions, and Triggers pages as the default settings.

How the override works: The default pages are the baseline for every app. An app profile only replaces the values you explicitly save for that app; any setting left untouched inherits the default. The profile is used when that app is active.

Manage profiles

Add an app

Tap the add button, choose an installed app, and confirm. A new app profile is created using inherited values.

Open an app’s settings

Tap the app in the list, then open the settings page you want to change.

Delete app settings

Delete the app profile to make that app use the default settings again.

  • TouchpadGive this app a different pad position, size, or appearance.
  • CursorGive this app a different cursor behavior.
  • SwipeChange scrolling, swipes, or zoom gestures for this app.
  • ActionsAssign app-specific taps, holds, flings, or dwell actions.
  • TriggersChange the app’s edge-trigger behavior.

Example

Use different scrolling in a video app

Open that app’s Actions page and change a tap or fling to match its controls. Leave the other pages unchanged so they continue to inherit the default profile.

If the on-screen keyboard is open, Keyboard settings are used for the keyboard context. Close it to return to the active app’s profile.
