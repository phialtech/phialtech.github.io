Conditional settings

Keyboard settings.

Use a different Scrool setup while the Android keyboard is open. Open this page from Settings > Keyboard settings.

Android page: Settings > Keyboard settings

The same pages, for typing

Keyboard settings are not a smaller set of controls. They contain the same Touchpad, Cursor, Swipe, Actions, and Triggers pages as the default settings.

How the override works: The default pages are the baseline. A keyboard setting only changes the value you explicitly save here; every other value continues to use the default. While the keyboard is open, these keyboard values are used. When it closes, Scrool returns to the applicable normal setup.

  • TouchpadMake the pad smaller, move it higher, or change its appearance for typing.
  • CursorUse a typing-friendly cursor position, size, or speed.
  • SwipeChange scrolling and zoom gestures while the keyboard is open.
  • ActionsUse different taps, holds, flings, or dwell actions.
  • TriggersChoose different edge-trigger behavior while typing.

Example

Keep the keyboard out of the way

Set a smaller Touchpad width and a higher Touchpad Y in the keyboard Touchpad page. Leave all other values alone. Scrool uses those two keyboard overrides while you type, then uses the regular values again afterward.

To return a single setting to the default, open that setting in the keyboard page and use its delete/reset control. To remove every keyboard override, reset Keyboard settings from the Apps list.
